# IA Futuro 🚀

**28 días · 15 minutos al día**

No es solo usar IA. Es aprender a dirigirla.

Curso práctico para aprender a elegir la herramienta correcta, dar instrucciones, crear trabajos estructurados y verificar resultados antes de entregar.

## Incluye
- Curso de 28 días
- Progreso local
- Biblioteca de herramientas
- Método D.I.R.I.G.E.
- Certificado de finalización

## Publicación
La aplicación es un sitio web estático y puede publicarse con GitHub Pages.
